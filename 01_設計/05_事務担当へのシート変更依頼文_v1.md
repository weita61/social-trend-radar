# 事務担当へのシート変更依頼文 v1

**状態**: 送付前レビュー待ち

---

リール動画投稿管理シートについて、今後導入するTrend Radarとの自動連携に対応したいです。

既存の数式や制作フローは残したまま、以下の変更をお願いします。

## 1. `Radar取込`タブを新規作成

列順:

1. Trend ID
2. 同期日時
3. 連携ステータス
4. トレンド名
5. ライフサイクル
6. 広域スコア
7. 確信度
8. 独立投稿者数
9. 確認媒体
10. 代表投稿URL
11. 表層記号
12. 表現構造
13. 根底欲求
14. 推奨フック
15. 推奨構成
16. 推奨CTA
17. 音源
18. 想定尺
19. Radar詳細URL
20. 担当メモ

`連携ステータス`は「未確認 / 構成案へ採用 / 見送り」のプルダウンにしてください。

## 2. `構成案ストック`へ3列追加

- Radar Trend ID
- Radar詳細URL
- トレンド構造

既存の「型」は今の制作分類として残し、「トレンド構造」とは別項目にしてください。

## 3. `制作PJ`へ2列追加

- 投稿URL
- Radar Trend ID

Radar Trend IDは元構成案Noを介して自動参照できる形が望ましいです。

## 4. 変更しない箇所

- A / R / Kから始まる通し番号
- 既存の型プルダウン
- 成果記録の保存率、エンゲージ率、判定式
- 担当者別進捗、型別集計、設定の既存ロジック

自動連携用GASはこちらで別途仕様を用意します。シート変更後、列位置だけ共有してください。
